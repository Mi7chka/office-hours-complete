# Week 8 · three checks for keep it running

Write the checks before the build. Run them with the sample business. Tick a check only when you saw it with your own eyes.

1. **Every number says what it is.** On the Summary tab, every number sits under Measured, Estimated or Projected, and each one says where it came from. There is no total across the three groups.
2. **A measured number is really counted.** The number for Cards waiting on you is the same as the number on the board's tile on the home screen.
3. **The backup comes back.** On the Backup tab, press Save a backup file. Then choose that file under Restore one file on purpose, read what the page says is in it, and press Put this backup back. The tile Restored on purpose shows today's date.
