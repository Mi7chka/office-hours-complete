# Week 3 · three checks for the email short list

Write the checks before the build. Run them with the sample business. Tick a check only when you saw it with your own eyes.

1. **Twelve in, twelve sorted.** The top of the page says 12 emails reviewed. Count the cards in the four piles. They add up to 12.
2. **The wrong one can be fixed.** In the FYI pile, find 3 invoices are overdue and move it to Reply today. The short list grows by one line, and the number on the home screen goes up by one.
3. **Nothing sends.** Press Copy the draft on one draft. A short message says it was copied, and nothing else happens. There is no Send button anywhere on the page.
